Geo-RAG Earth Dashboard

  • Tech Stack: Python, FastAPI, Next.js, TypeScript, PostgreSQL (PostGIS + pgvector), MapLibre GL, Three.js, RemoteCLIP, Kafka-free event telemetry, Docker, GitHub Actions
  • Website URL: Link

Full-stack GeoAI dashboard that answers natural-language questions ("turquoise coastal water", "desert near shoreline") against Sentinel-2 satellite imagery of the Saudi Red Sea coast. Embeddings are precomputed offline with RemoteCLIP and searched in-process with pgvector cosine similarity, alongside PostGIS bounding-box queries on an interactive MapLibre map with a score-elevated Three.js view and a telemetry timeseries panel.

Production-grade details: JWT authentication with rotating refresh tokens and reuse revocation, rate limiting, traversal-safe thumbnail serving (true-color and false-color composites), security headers, and a fixture-seeded Docker Compose quickstart that goes from git clone to a working search in about two minutes — no external services required. Benchmarks and architecture notes are documented in the repository.
